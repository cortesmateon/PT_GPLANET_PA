# Prueba_GPLANET

Aplicación web de ejemplo (Flask + Angular) para prueba técnica.

## Requisitos mínimos

| Herramienta | Versión |
|-------------|---------|
| Python | 3.10 o superior |
| Node.js | 20.19 o superior |
| npm | 10 o superior |
| Git | cualquier versión reciente |

No requiere archivo `.env`, base de datos externa ni cuentas de nube.
